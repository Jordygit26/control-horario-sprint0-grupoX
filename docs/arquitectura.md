# Arquitectura del Proyecto

## Stack
- Frontend: Antigravity (React / Next)
- Backend: Supabase
- Auth: Supabase Auth
- DB: PostgreSQL (Supabase)

## Flujo general
1. Usuario se registra o inicia sesión
2. Accede al dashboard
3. Inicia y finaliza jornada
4. Las jornadas se guardan en Supabase
5. El usuario puede ver su historial
